# 红发少女 · 互动展示

公网演示：https://heart7th.github.io/redhair-showcase/

基于单张立绘的 2.5D WebGL 互动演示，包含抬手、挥手、九组表情的左右转脸、全身/面部/肩袖视角。手臂采用连续袖管网格连接上臂、肘部和前臂。网页为自包含 `index.html`，无后端服务和外部图片依赖。

点击“逐个表情转脸”可轮播全部九种表情；`face-turns.mp4` 提供完整转脸录像。当前为单张正面立绘的 2.5D 小角度转脸，极限弯肘处仍有少量纹理压缩。

`source.zip` 提供对应预览代码、运行时源码、构建脚本、绑定数据、图集与所用素材。解压后按包内 README 构建。

代码基于 myriad-figure（AGPL-3.0，含 MIT 来源）；完整来源及许可证见 `licenses/`。人物图像为演示素材，不因代码开源而另行授予图像许可。
