# 红发少女 · 互动展示

公网演示：https://heart7th.github.io/redhair-showcase/

基于单张立绘的 2.5D WebGL 互动演示，包含抬手、挥手、九组表情的左右转脸与抬头、低头、全身/面部/肩袖视角。衣袖使用五组原画关键姿态与局部配准，手臂通过肘部向镜头收短完成换面。头部关闭颅骨弹性拉伸，保留发丝摆动。网页为自包含 `index.html`，无后端服务和外部图片依赖。

点击“逐个表情转脸”可轮播全部九种表情；`face-turns.mp4` 提供完整四方向转脸录像。当前为单张正面立绘的 2.5D 小角度转脸，按钮采用缓起缓停。`sleeve-motion.mp4` 提供整段袖管动作录像。

`source.zip` 提供对应预览代码、运行时源码、构建脚本、绑定数据、图集与所用素材。解压后按包内 README 构建。

代码基于 myriad-figure（AGPL-3.0，含 MIT 来源）；完整来源及许可证见 `licenses/`。人物图像为演示素材，不因代码开源而另行授予图像许可。
