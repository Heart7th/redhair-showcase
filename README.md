# 红发少女 · 互动展示

公网演示：https://heart7th.github.io/redhair-showcase/

基于单张立绘的 2.5D WebGL 互动演示，包含抬手、挥手、九组表情的左右转脸与抬头、低头、全身/面部/肩袖视角。画面右侧手臂的举手逐帧取自生成视频：即梦 Seedance 生成抬手动作，SAM 2.1 逐帧抠出袖子与手，贴在原角色的躯干上随身体移动，脸、表情和头发仍为原绑定。抬头与低头使用面部深度投影，关闭颅骨弹性拉伸，保留发丝摆动。网页为自包含 `index.html`，无后端服务和外部图片依赖。

点击“逐个表情转脸”可轮播全部九种表情；`face-turns.mp4` 提供完整四方向转脸录像。当前为单张正面立绘的 2.5D 转脸与俯仰；俯仰绕颈顶转动，五官和下巴一起滑动，头发外轮廓几乎不动，低头露出头顶、抬头露出脖子，按钮采用缓起缓停。`head-pitch.mp4` 是中性表情抬低头的八秒近景。

连续演示按视频原帧率播放：抬到胸前、沿画面右侧举到耳旁、挥手，再沿原路放下；按钮与滑杆在相邻帧之间淡化。`sleeve-motion.mp4` 是整段举手的肩袖近景录像。

`source.zip` 提供对应预览代码、运行时源码、构建脚本、绑定数据、图集与所用素材。解压后按包内 README 构建。

代码基于 myriad-figure（AGPL-3.0，含 MIT 来源）；完整来源及许可证见 `licenses/`。人物图像为演示素材，不因代码开源而另行授予图像许可。
